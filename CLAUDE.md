# Project Instructions for Claude

## Git Workflow - IMPORTANT
- **Never commit directly to main** - always create a separate branch first
- **Never `git commit` without explicit user consent** - make the file changes, then ask before committing
- **Never push without explicit user consent**
- Always seek user consent before:
  - Committing changes (`git commit`)
  - Pushing a branch to remote
  - Creating a pull request
  - Merging a pull request
- This applies to ALL repos, including deploy clones (e.g. the Hugging Face Space repo), not just this one

## Git Commits & PRs
- Do NOT reference Claude or AI in commits, PR titles, or PR descriptions
- Keep commit messages concise and descriptive
